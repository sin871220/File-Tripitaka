# 파일만대장경

압축파일 안의 대표 사진을 썸네일로 모아 보고, 꿀뷰 등 외부 뷰어로 열 수 있는 Windows용 프로그램입니다.

## 이번 버전

- 확정된 먹빛·각진 목판, 주황 돋보기, 흰 사진 표시 아이콘을 앱과 EXE 빌드에 적용했습니다.
- 설정 창의 모든 탭에서 스크롤 영역·스크롤바·휠 스크롤 처리를 제거했습니다.
- 설정 창은 내용에 맞춰 크기를 잡습니다. 조작부 글자는 최대 12pt로 유지하고, 글꼴 미리보기는 선택한 크기로 표시합니다.
- 왼쪽 즐겨찾는 폴더·폴더 탐색의 독립적인 접기 및 상태 기억 기능을 포함합니다.
- 이전 `%LOCALAPPDATA%\ArchiveShelf` 저장 위치를 유지해 즐겨찾기·설정·캐시를 이어서 사용합니다.

## 실행과 EXE 빌드

1. Windows에 Python 3.12 이상(Tcl/Tk 포함)을 설치합니다.
2. 이 폴더를 풀고 `run-windows.bat`을 실행합니다. 최초 패키지 설치에는 인터넷 연결이 필요합니다.
3. 폴더를 선택합니다. 하위 폴더 전체를 모으려면 설정의 관련 옵션을 켭니다.
4. `설정 → 일반`에서 더블클릭 동작과 뷰어 경로를 지정합니다.

`build-windows.bat`을 실행하면 테스트 후 `dist/FileManDaejanggyeong.exe`가 생성됩니다. EXE를 사용하는 PC에는 Python이 필요 없습니다. 꿀뷰와 RAR·7Z용 7-Zip은 별도로 설치해야 합니다. 이전 EXE는 다시 빌드해야 새 아이콘과 수정이 적용됩니다.

`assets`와 `fonts` 폴더를 함께 유지하세요. 이 배포물은 소스와 빌드 스크립트이며 미리 빌드된 Windows EXE는 포함하지 않습니다.

GitHub 저장소 루트에 이 폴더 내용을 올리면 Actions → Build Windows EXE → Run workflow에서 빌드할 수도 있습니다. 원격 업로드나 빌드는 자동 실행하지 않았습니다.

## 주요 기능

- ZIP·CBZ, 7-Zip 설치 시 RAR·CBR·7Z·CB7 대표 이미지 표시. 내부 이미지의 파일명을 자연 정렬해 첫 이미지를 사용합니다.
- 하위 폴더 검색, 이름·수정한 날짜 오름/내림차순, 연속 스크롤과 화면 근처 카드만 생성하는 방식.
- 전체 탭과 폴더에 관계없는 전역 즐겨찾기 탭. 전체 탭의 즐겨찾기 항목은 우측 상단 노란 별로 표시합니다.
- 즐겨찾기 추가·해제는 살아 있는 카드를 재사용하며, 해제 시 현재 픽셀 스크롤을 유지합니다. 목록 끝이 줄어들면 새 끝까지로 보정합니다.
- 폴더·탭별 보던 파일 위치 기억, 폴더 즐겨찾기, 뒤로 가기·맨 위로 이동, 썸네일 크기 조절.
- 우클릭으로 즐겨찾기·파일 정보·파일 위치 열기·꿀뷰 열기·경로 복사.
- 미리보기 불가 항목은 더블클릭 설정에 관계없이 파일 위치 열기를 실행합니다.

## 설정

- 일반: 라이트 / 다크 / 네이비 / 블루, 더블클릭 동작(파일 위치·꿀뷰·다른 뷰어), 뷰어 경로, 하위 폴더 포함.
- 표시 설정: 파일명·용량·날짜 체크, 파일명 확장자 표시/숨김.
- 글꼴: 설치된 글꼴 또는 자동 CJK 선택, 8~24pt, 한글·일본어·한자 미리보기.
- 적용하면 저장하고 취소하면 변경하지 않습니다. 외부 프로그램에는 압축파일 경로를 별도 인자로 전달하며 추가 명령줄 옵션은 지원하지 않습니다.
- Noto Sans CJK KR 글꼴은 Windows에서 현재 프로세스에만 등록합니다. 출처와 라이선스는 `fonts/SOURCE.txt`, `fonts/OFL.txt`를 참고하세요.

## 저장 위치와 제한

설정·즐겨찾기: `%LOCALAPPDATA%\ArchiveShelf\settings.json`

썸네일 캐시: 같은 폴더의 `cache` (프로그램 종료 후 지워도 재생성됩니다.)

진단 로그: `error.log`, `crash.log`. 운영체제가 강제 종료하면 로그가 남지 않을 수도 있습니다.

원본 압축파일을 수정하지 않습니다. 암호·손상·중첩·분할 압축은 미리보기가 제한될 수 있습니다. 대표 이미지 파일의 압축 해제 후 바이트 크기는 64MB까지 지원합니다. 이미지 형식은 JPG·JPEG·PNG·WebP·BMP·GIF·TIFF입니다. 꿀뷰로 실제 열 수 있는 형식은 설치된 꿀뷰 버전에 따릅니다.

큰 이미지는 별도 libvips 디코더에서 한 장씩 처리하고, RSS 512MB 초과 또는 45초 초과 시 종료합니다. 메모리는 약 50ms 간격 감시이므로 순간 사용량의 절대 상한은 아닙니다. 사진 미리보기 실패가 파일 자체의 열기 실패를 뜻하지는 않습니다.

즐겨찾기는 파일 경로 기준입니다. 이동·이름 변경 또는 외장 디스크 미연결 시 등록 항목이 미리보기 불가로 남을 수 있습니다.

## 검증과 아이콘

자동 테스트 22개 통과. 실제 macOS Tk GUI에서 7,444개 목록, 탭 전환·위치 복원, 즐겨찾기 부분 갱신, 테마·글꼴·표시 설정, 왼쪽 접기·펼치기, 설정 창 스크롤 위젯 부재와 버튼 표시를 검증했습니다. Windows EXE 빌드·실제 꿀뷰 및 탐색기 연동·글꼴 등록은 Windows에서 추가 확인이 필요합니다.

아이콘은 내장 이미지 생성 도구로 제작한 최종 승인 시안을 사용합니다. `assets/app.png`는 투명 원본, `assets/app.ico`는 16~256픽셀 Windows 아이콘입니다. 최종 편집 프롬프트는 `assets/ICON-PROMPT.txt`에 기록했습니다.

## 키보드 조작 및 여러 장 썸네일

- 카드를 한 번 클릭하면 선택 테두리가 표시되고 썸네일 목록에 키보드 초점이 갑니다. 방향키로 현재 배치의 좌우·위아래 카드로 이동하며 화면 밖으로 나가면 자동 스크롤합니다. 입력창·폴더 트리·설정 창의 키 입력은 카드 단축키와 분리됩니다.
- 설정 → 열기 동작에서 더블클릭 / Enter / Space를 각각 독립적으로 지정합니다. 세 항목의 공통 옵션은 파일 위치 열기 / 꿀뷰 열기 / 다른 뷰어 프로그램 열기이고, Enter·Space에만 없음이 추가됩니다. 처음에는 기존 더블클릭 설정을 초기값으로 사용합니다.
- 사용 중인 동작에 필요한 꿀뷰·다른 뷰어 경로가 표시됩니다. 서로 다른 동작에서 두 뷰어를 함께 쓰면 두 경로를 모두 지정할 수 있습니다. 미리보기 불가 파일은 기존처럼 파일 위치 열기로 연결되며, 키 동작이 없음인 경우에는 실행하지 않습니다.
- 썸네일 도구줄의 기본값은 1장입니다. 원할 때 2장 / 3장을 선택하면 카드 폭을 장수에 맞게 늘려 이미지를 겹침 없이 가로로 나란히 보여줍니다. 왼쪽부터 2장은 2·1, 3장은 3·2·1 순서이며 각 이미지의 비율을 유지합니다.
- 순차 보기: 파일명 자연 정렬의 맨 앞 1·2·3번째 이미지.
- 비율 보기: 2장은 맨 앞과 1/2 위치, 3장은 맨 앞과 1/3·2/3 위치. 전체 이미지 개수 기준 0부터 센 위치를 내림하여 고릅니다. 예: 12장 중 3장 비율은 1·5·9번째입니다.
- 1장에서는 순차/비율 옵션이 비활성화됩니다. 이미지 수가 부족하면 실제 장수만 표시하며 중복시키지 않습니다. 첫 사진은 정상이고 뒤의 샘플만 읽기 실패하면 정상 사진만 표시합니다.
- 선택한 보기 방식은 저장하며, 모드별 썸네일을 따로 캐시합니다. 2·3장 보기는 압축 내부 사진을 더 읽으므로 최초 생성은 1장보다 오래 걸릴 수 있습니다. 화면 근처 카드만 처리하는 제한은 유지합니다.

검증: 자동 테스트 25개 통과. 실제 Tk GUI에서 선택·방향키 이동·끝 경계·자동 스크롤, 독립 실행 설정, Enter/Space에만 없음 옵션, 1장 기본값·2/3장 전환·옵션 활성 상태·선택 및 위치 복원, 기존 7,444개 목록 동작을 확인했습니다. Windows의 실제 외부 프로그램 실행과 표시 동작은 추가 확인이 필요합니다.

Enter와 Space의 동작 설정에서 **즐겨찾기 추가/해제**를 선택하면 선택한 압축파일의 즐겨찾기를 전환합니다. 미리보기가 불가능한 파일에도 적용됩니다.

상단의 **폴더 패널 접기 / 펼치기** 버튼으로 왼쪽 사이드바 전체를 숨기거나 복원합니다. 접으면 썸네일 영역이 넓어지며 접힘 상태는 다음 실행에도 유지됩니다.

Windows 폴더 탐색에는 연결된 드라이브 문자(C:, D:, 이동식·네트워크 드라이브 등)를 모두 표시합니다. 각 드라이브는 펼칠 때 하위 폴더를 불러오며 현재 위치 바로가기도 유지합니다.

폴더 탐색은 드라이브·닫힌 폴더·열린 폴더 아이콘으로 구분합니다. 즐겨찾는 폴더는 폴더 아이콘과 폴더명만 표시하며, 마우스를 올리면 하단 상태줄에서 전체 경로를 확인할 수 있습니다.

즐겨찾는 폴더는 한 번 클릭하면 전체 탭에서 해당 폴더의 썸네일 목록을 표시합니다. Enter로도 열 수 있습니다.

제목 표시줄에 버전(v1.1.0)을 표시합니다. Windows 11에서는 제목 표시줄 배경과 글자색도 선택한 테마에 맞춥니다. 지원하지 않는 Windows 환경에서는 기본 제목 표시줄이 유지됩니다.

폴더 탐색에서도 폴더 이름이나 아이콘을 한 번 클릭하면 전체 탭에 해당 폴더의 썸네일이 표시됩니다. 화살표는 하위 폴더만 접고 펼치며, 폴더 이동 시 탐색 트리의 펼침 상태를 유지합니다.

폴더 탐색에서 한 번 클릭은 썸네일 표시, 더블클릭은 하위 폴더 펼치기·접기로 동작합니다. 두 번째 클릭은 중복 폴더 스캔을 실행하지 않습니다.

썸네일 카드는 바깥 간격 없이 맞닿는 격자로 표시하며 인접 테두리를 1px 겹쳐 경계선 하나로 구분합니다. 카드 내부 이미지·텍스트 여백과 선택 강조는 유지합니다.

2·3장 이미지 사이는 실제 이미지 폭을 기준으로 좁은 여백만 두고 배치합니다. 이미지 비율과 2·1 / 3·2·1 순서는 유지합니다.

썸네일 크기 슬라이더 오른쪽의 **창에 맞춤** 버튼은 버튼을 누른 시점의 열 수를 유지한 채 카드들이 창 너비를 정확히 채우도록 크기를 조절합니다. 4열이면 4열, 5열이면 5열을 유지하고 창 크기를 바꿔도 같은 열 수로 맞춥니다. 슬라이더를 직접 조절하거나 1·2·3장 보기를 바꾸면 수동 크기로 돌아갑니다. 선택한 파일과 스크롤 기준 위치는 유지합니다.

**창에 맞춤 ON/OFF**는 체크박스 모양이 아닌 토글 버튼입니다. 켜짐 상태는 강조색과 ON으로 표시하며 다시 누르면 꺼집니다. 슬라이더 조작 또는 보기 방식 변경 시 OFF로 함께 바뀝니다.


한국어 / English (v1.1.0)
------------------------
설정 → 일반 → 언어에서 한국어 또는 English를 선택하고 적용하면 재시작 없이 메뉴·버튼·설정·정렬 및 동작 옵션·상태 문구와 창 제목이 바뀝니다. 한국어 제목은 파일만대장경, 영어 제목은 File Tripitaka이며 언어 선택은 저장됩니다. 파일명·폴더명·경로는 번역하지 않습니다.

Windows EXE로 실행할 때 언어를 변경하면 사용자 바탕화면 및 공용 바탕화면에서 **현재 실행 중인 EXE를 정확히 가리키는 기존 .lnk 바로가기**의 이름도 파일만대장경 / File Tripitaka로 변경합니다. 바로가기 대상·아이콘·인수는 유지하며 EXE 파일명은 바꾸지 않습니다. 다른 프로그램 바로가기는 변경하지 않고, 같은 이름의 다른 바로가기가 있으면 덮어쓰지 않습니다. 바로가기가 없으면 새로 만들지는 않습니다. 권한 등으로 변경에 실패하면 안내가 표시됩니다. Python 소스 실행에서는 바로가기를 변경하지 않습니다.

검증: 자동 테스트 33개 통과. 실제 Tk GUI에서 한국어→영어→한국어 전환, 영어 설정·정렬·즐겨찾기 동작, 파일명 보존, 기존 카드와 선택 유지 및 재실행 시 언어 복원을 확인했습니다. Windows의 실제 바로가기 이름 변경은 Windows EXE에서 확인이 필요합니다.
