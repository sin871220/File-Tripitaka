## 다운로드

**현재 버전은 1.3.0입니다.** 이미지 폴더 썸네일, 폴더 탭, 썸네일 위 표시 설정과 왼쪽 폴더 패널 조절을 추가했습니다. 즐겨찾는 폴더는 드래그로 정렬하고 확인창을 거쳐 등록과 탭만 제거할 수 있습니다. [1.3.0 업데이트 내역](RELEASE-NOTES.md)을 확인하세요.

[v1.3.0 다운로드 페이지](https://github.com/sin871220/File-Tripitaka/releases/tag/v1.3.0)에서 내 컴퓨터에 맞는 ZIP을 받으세요. Python을 따로 설치할 필요가 없습니다.

각 ZIP의 `THIRD-PARTY` 폴더에 Tcl/Tk와 포함 라이브러리의 라이선스·고지문이 들어 있습니다. `SHA256SUMS.txt`로 다운로드한 파일의 무결성을 확인할 수 있습니다.

현재 배포 파일은 **배포자 코드 서명·Apple 공증이 없어** 운영체제의 실행 경고나 차단이 나타날 수 있습니다. 자세한 실행 조건은 [배포 안내](RELEASE-NOTES.md)를 확인하세요. 이전 버전과 변경 사항은 [전체 Releases](https://github.com/sin871220/File-Tripitaka/releases)에 모아 둡니다.

## 처음 사용하기

1. **폴더 선택**을 눌러 압축파일이 있는 폴더를 고르세요. 하위 폴더까지 모아 보는 옵션은 기본으로 켜져 있습니다.
2. **전체** 탭에서 썸네일을 둘러보세요. 파일명으로 검색하고 종류로 걸러 보거나 이름·수정 날짜·용량 순으로 정렬할 수 있습니다.
3. 자주 찾는 파일은 **오른쪽 클릭 → 즐겨찾기 추가**로 모아 두세요. **즐겨찾기** 탭은 현재 폴더와 관계없이 모든 파일 즐겨찾기를 보여 줍니다.
4. **설정 → 열기 동작**에서 더블클릭 동작과 뷰어 경로를 고르세요. **설정 → 단축키**에서는 기능별로 키를 지정합니다. Windows에서는 꿀뷰나 다른 뷰어를, Mac에서는 기본 앱이나 다른 뷰어를 연결할 수 있습니다.

Mac의 기본 더블클릭 동작은 **Finder에서 파일 위치 열기**입니다. **기본 앱으로 열기**는 macOS의 파일 연결을 따르므로 압축 해제 프로그램이 열릴 수도 있습니다. 외부 뷰어와 Windows용 꿀뷰는 포함하지 않으며, 따로 설치해야 합니다.

### 마우스와 키보드

| 조작 | 동작 |
|---|---|
| 왼쪽 폴더 이름 한 번 클릭 | 해당 폴더의 썸네일 표시 |
| 폴더 탐색에서 더블클릭 / 화살표 클릭 | 하위 폴더 펼치기·접기 |
| 썸네일 한 번 클릭 → 방향키 | 파일 선택 후 그리드 안에서 이동 |
| 더블클릭 | 열기 동작에서 설정한 동작 실행 |
| Enter / Space 및 지정한 단축키 | 단축키 설정에서 해당 키에 지정된 기능 실행 |
| 오른쪽 클릭 | 파일 위치·즐겨찾기 등 메뉴 열기. Mac은 보조 클릭·Control-click도 지원 |
| 파일 선택 → F2 (기본값) | 압축파일 이름 변경. 확장자는 유지하며 같은 이름의 파일을 덮어쓰지 않음 |
| 파일 선택 → Delete (기본값) | 확인 후 원본 압축파일을 휴지통으로 이동. Mac은 Command+Backspace도 지원 |

기존 Enter·Space 동작은 기능별 단축키로 자동 이전합니다. 이전에 **없음**으로 설정한 키는 미할당으로 유지하고, 더블클릭 설정은 독립적으로 보관합니다. 즐겨찾기 탭에서 단축키로 해제하면 스크롤을 유지하며 다음 파일을 선택하고, 마지막 파일이면 이전 파일을 선택합니다.

### 기능별 단축키

**설정 → 단축키**에서 파일 위치 열기, 뷰어로 열기, 다른 뷰어로 열기, 즐겨찾기 추가/해제, **썸네일 영역 편집**, 이름 바꾸기, 휴지통 이동, **폴더 패널 접기/펴기**, **창에 맞춤 ON/OFF**에 각각 키를 두 개까지 지정할 수 있습니다. 키 버튼을 누른 뒤 원하는 키 또는 Ctrl·Shift·Alt 조합을 누르세요. Mac은 Cmd 조합도 지원합니다.

**썸네일 영역 편집**의 기본 단축키는 미할당이며 기존 키 설정을 유지합니다. 파일을 선택하고 썸네일 영역에서 지정한 키를 누르면 편집기가 열립니다. 검색·파일명 입력 중이나 다른 대화상자에서는 실행하지 않습니다. 지정한 키는 우클릭 메뉴에도 표시합니다.

폴더 패널과 창에 맞춤은 기본 단축키가 미할당이며 기존 설정에 새 항목만 추가됩니다. 두 기능은 썸네일을 클릭하지 않아도 메인 창의 폴더 탐색·즐겨찾는 폴더·버튼 등에서 사용할 수 있습니다. 파일 선택이 없거나 빈 폴더여도 동작하며, 검색·경로 입력·설정창에서는 입력을 가로채지 않습니다. 창에 맞춤은 기존 버튼과 똑같이 ON/OFF를 전환합니다.

- 다른 기능에 이미 할당한 키는 충돌 안내와 함께 거부하며 기존 할당을 덮어쓰지 않습니다.
- 할당 해제로 해당 칸을 비울 수 있습니다. 기본값 복원은 단축키만 초기화하고 더블클릭·테마·즐겨찾기는 유지합니다.
- 설정 변경과 기본값 복원은 **적용**을 누르면 저장됩니다. 취소하면 기존 설정을 유지합니다.
- 파일 작업 단축키는 썸네일 영역에 포커스가 있을 때 동작합니다. 폴더 패널·창 맞춤은 메인 창의 다른 영역에서도 사용할 수 있습니다. 검색창이나 이름 입력 중에는 파일 삭제·이름 변경을 실행하지 않습니다. 방향키·Tab·Esc 같은 기본 탐색 키는 보호합니다.

이름 변경과 삭제는 우클릭 메뉴에서도 사용할 수 있습니다. 삭제한 파일은 전체 목록과 즐겨찾기에서 함께 빠지며 다음 파일이 선택됩니다. 스크롤은 유지하고, 목록 끝에서는 남은 목록 높이에 맞춰 조정합니다. 휴지통을 사용할 수 없는 위치에서는 삭제하지 않습니다. 휴지통에서 복원한 파일은 **새로고침**으로 다시 불러올 수 있으며, 즐겨찾기는 다시 추가해야 합니다.

이름 변경창은 **원래 파일명이 한 줄에 들어오도록 너비를 자동으로 맞추며**, 화면보다 긴 이름은 줄바꿈합니다. 원래 이름은 드래그 선택·복사가 가능한 읽기 전용입니다. 창 크기는 직접 조절할 수 있고, 새 이름 입력칸과 버튼이 가려지지 않도록 최소 크기를 적용합니다.

### 1장·2장·3장 미리보기

**1.3.0**에서는 이미지가 직접 들어 있는 폴더도 카드로 모아 봅니다. **종류 → 전체 / 압축파일 / 폴더**로 고르고 검색·정렬을 함께 사용하세요. 정렬은 **이름 ▲·▼ / 수정 날짜 ▲·▼ / 용량 ▲·▼**, 배치는 **섞어서 / 폴더 먼저 / 파일 먼저**에서 고릅니다. ▲·▼를 바꿔도 그룹 순서는 유지하고 각 그룹 내부에서 정렬합니다. 기본 배치는 섞어서이며, 종류를 하나만 표시할 때는 배치 선택이 비활성화됩니다. 탭별 선택과 스크롤 위치는 다시 열 때도 기억합니다. 폴더 카드에는 작은 폴더 표시가 있으며, 아래의 1장·2장·3장 미리보기·즐겨찾기·영역 편집을 그대로 사용합니다. 폴더 즐겨찾기는 왼쪽의 탐색 폴더 즐겨찾기와 별개로 전역 즐겨찾기 탭에 모입니다. 페이지 수 정렬과 전체 목록의 개수 계산은 제거했습니다. 이전 페이지 수 정렬 설정은 이름 ▲로 전환하며, 썸네일의 페이지 수 표시는 유지합니다. 용량은 카드에 표시된 값을 사용합니다.

**폴더 탭:** 즐겨찾기 바로 오른쪽의 **＋**에서 즐겨찾는 폴더를 골라 별도 탭으로 엽니다. 이미 열린 폴더는 메뉴에 **✓**로 표시합니다. **전체·즐겨찾기·＋는 고정**하고 폴더 탭만 휠·좌우 버튼으로 가로 이동합니다. 좌우 버튼은 탭이 영역을 넘을 때만 나타나며, 폴더 탭을 드래그해 순서를 바꿀 수 있습니다. 전체 탭의 기준 폴더는 유지하며, 각 폴더 탭의 검색·정렬·종류·배치·선택·스크롤 위치를 따로 기억합니다. 탭 순서·활성 탭·보기 상태는 재실행해도 복원하고, **×**로 닫아도 실제 폴더와 파일 즐겨찾기는 유지합니다.

**왼쪽 패널:** 즐겨찾는 폴더와 폴더 탐색 사이의 구분선을 위아래로 드래그해 높이를 조절합니다. 어느 쪽을 접어도 반대쪽이 남은 공간을 채우며, 다시 펼치거나 재실행하면 이전 분할 비율로 돌아갑니다. 즐겨찾는 폴더 목록이 길어지면 세로 스크롤바가 나타나며, 휠로도 이동할 수 있습니다. 사이드바 폭을 줄여도 스크롤바 너비를 확보합니다.

**즐겨찾는 폴더:** 폴더를 위아래로 드래그해 순서를 바꾸면 **＋ 메뉴와 재실행**에도 반영합니다. 목록 가장자리에서는 자동 스크롤하고 **Escape**로 변경을 취소합니다. **제거** 확인창에서 **예**는 즐겨찾기 등록과 해당 탭 제거, **아니오**는 취소입니다. 확인창에도 **실제 폴더와 파일은 삭제되지 않습니다.** 안내를 표시합니다. 파일별 즐겨찾기는 유지하고, 제거한 폴더 탭이 활성 탭이면 전체 탭으로 돌아갑니다.

**설정 → 표시 설정 → 썸네일 위 표시**에서 별·폴더·페이지 수의 표시 여부와 네 모서리 위치를 각각 고릅니다. 손잡이나 항목 이름을 **드래그**해 순서를 바꿉니다. 행을 클릭해 선택하고 **위로 / 아래로** 버튼을 사용해도 됩니다. 같은 위치에는 목록의 위에서 아래 순서로 쌓이며, 숨긴 표시는 빈칸을 남기지 않습니다. 기본 순서는 별 → 폴더 → 페이지입니다. 별·폴더 아이콘은 **크게(기존 크기) / 보통(2/3) / 작게(1/2)** 중 고릅니다. 페이지 수는 **4~72pt**를 숫자로 지정하며 기본값은 **10pt**입니다. 페이지 글자 크기는 앱 글자 크기와 독립적으로 저장합니다. 페이지 수에는 글씨 색·배경색·배경 알파(0~100%)도 지정합니다. 알파 0%는 배경 완전 투명, 100%는 불투명입니다. 기본 위치는 별 오른쪽 위·폴더 왼쪽 위·페이지 오른쪽 아래이고, 즐겨찾기 탭에서는 별을 숨깁니다. 페이지 수는 지원 이미지 전체 개수(폴더는 바로 안의 이미지)이며, 2장·3장 보기에서도 그룹당 한 번만 표시합니다. 미리보기와 기본값 복원을 제공하고, 적용할 때 기존 카드와 스크롤 위치를 유지합니다.

폴더의 뷰어 열기는 대표 이미지(저장한 1번 이미지 또는 첫 이미지)를 열고, 파일 위치 열기는 해당 폴더를 엽니다. 폴더 용량은 직접 포함된 이미지의 합계입니다. 폴더 카드의 이름 변경·휴지통 이동은 비활성화되어 있습니다. 폴더 이름·위치 변경 후에도 내부 이미지 이름과 내용이 같으면 편집을 복원하며, 이미지 추가·삭제·이름·내용 변경 시에는 새 구성으로 인식합니다.

기본은 **1장 보기**입니다. 2장·3장 보기는 카드의 폭을 넓혀 이미지를 작은 간격으로 나란히 배치합니다.

| 선택 | 순차 보기에서 고르는 이미지 | 비율 보기에서 고르는 이미지 | 화면의 왼쪽 → 오른쪽 |
|---|---|---|---|
| 1장 | 맨 앞 | 맨 앞 | `1` |
| 2장 | 1·2번째 | 맨 앞 · 1/2 위치 | `2 → 1` |
| 3장 | 1·2·3번째 | 맨 앞 · 1/3 · 2/3 위치 | `3 → 2 → 1` |

화면 순서의 숫자는 선택된 이미지의 순서입니다. 맨 앞 이미지가 오른쪽에 옵니다. 이미지가 부족하면 실제 장수만 표시하고 같은 이미지를 중복하지 않습니다.

### 썸네일 영역 편집

가로나 세로로 긴 이미지에서 원하는 부분을 대표 썸네일로 고를 수 있습니다.

1. 압축파일 썸네일을 선택한 뒤 **썸네일 크기·창에 맞춤·미리보기와 같은 줄 오른쪽의 썸네일 영역 편집 버튼**을 누르세요. **오른쪽 클릭 → 썸네일 영역 편집** 또는 **설정 → 단축키**에서 지정한 키로도 열 수 있습니다.
2. **썸네일 위치**와 압축파일 안의 이미지를 고르세요. 2장·3장 보기에서는 위치마다 다른 이미지와 영역을 저장할 수 있습니다. **1번은 오른쪽**이며 이미지가 부족하면 실제 장수만 선택할 수 있습니다.
3. 기본은 **자유 비율**입니다. 미리보기에서 드래그해 영역을 만들고, 안쪽을 끌어 이동하거나 테두리의 손잡이로 크기를 바꾸세요. **썸네일 비율 (127:180)**을 고르면 1270×1800과 같은 세로 비율로 고정합니다. 원본 비율과 전체 이미지 선택도 지원하며, 휠·슬라이더로 확대하고 **Space+드래그**로 이미지를 이동할 수 있습니다.
4. 오른쪽 미리보기로 결과를 확인하고 **적용**을 누르세요. 창을 열어 둔 채 다른 썸네일 위치도 편집할 수 있습니다. 저장한 영역을 지우려면 해당 위치를 선택하고 **자동 썸네일로 복원**을 누르세요.

**원본 압축파일과 내부 이미지는 변경하지 않습니다.** 이미지 이름과 선택 영역만 별도 저장하며, 적용하지 않은 선택은 닫을 때 저장하지 않습니다.

적용·복원 시에는 일반 썸네일 생성 대기열과 별도로 해당 미리보기를 갱신합니다. 새 이미지가 준비될 때까지 기존 썸네일을 보여 주고, 준비되면 카드의 이미지만 교체하며 스크롤 위치·선택·다른 카드를 유지합니다.

EXIF 회전 정보를 반영한 화면을 기준으로 영역을 저장합니다. 확대된 작은 미리보기를 다시 자르는 대신 **원본 이미지의 해당 영역을 자른 뒤 축소**하며, 큰 이미지는 별도 디코더로 처리합니다.

편집 내용은 경로 대신 **압축파일 내용으로 만든 식별값**에 연결합니다. 이름을 바꾸거나 폴더·드라이브를 옮겨도 다시 읽을 때 복원하고, 내용이 같은 복사본에도 같은 편집 내용을 적용합니다. 압축파일 내용이 바뀌거나 다시 압축하면 다른 파일로 인식할 수 있어 영역을 다시 지정해야 할 수 있습니다.

영역 편집은 설정 폴더의 **`thumbnail_edits.json`**에 저장합니다. 다른 컴퓨터에서도 유지하려면 압축파일뿐 아니라 이 파일도 설정과 함께 옮겨야 합니다. [운영체제별 설정 위치](#문제를-발견했나요)를 참고하세요.

### 화면 꾸미기

- **창에 맞춤 ON/OFF:** 현재 4열이면 4열, 5열이면 5열을 유지하면서 창 너비를 채웁니다. 슬라이더를 움직이면 OFF로 돌아옵니다.
- **폴더 패널 조절:** 사이드바 전체를 접어 썸네일 영역을 넓힙니다. 즐겨찾는 폴더와 폴더 탐색 사이의 구분선을 위아래로 드래그해 높이를 조절할 수 있습니다. 각 제목을 눌러 한쪽을 접으면 다른 쪽이 남은 공간을 채우고, 다시 펼치면 이전 비율로 돌아갑니다. 분할 비율은 재실행해도 기억합니다.
- **테마:** 라이트 · 다크 · 네이비 · 블루.
- **카드 표시:** 파일명, 확장자, 용량, 수정 날짜 중 필요한 항목만 표시합니다.
- **글꼴·언어:** 글꼴과 글자 크기를 바꾸고, 한국어 / English를 선택할 수 있습니다. 제목·메뉴·설정이 함께 바뀌며 파일명은 그대로 유지합니다.
- **대화상자 위치:** 설정창은 메인 창 중앙에, 단축키 할당·이름 변경창은 부모 창 중앙에 열립니다. Windows에서는 해당 모니터의 작업 영역 안으로 위치를 조정합니다.

## 어떤 파일을 볼 수 있나요?

| 종류 | 지원 |
|---|---|
| 압축파일 | ZIP · CBZ 기본 지원 / RAR · CBR · 7Z · CB7은 별도 7-Zip 필요 |
| 압축파일 안의 이미지 | JPG · JPEG · PNG · WebP · BMP · GIF · TIFF |

**7-Zip은 배포 파일에 포함하지 않습니다.** 설치된 `7z`·`7zz`를 PATH와 일반적인 설치 경로에서 찾으며 Mac의 Homebrew 경로도 확인합니다. 내부 이미지 이름은 자연 정렬합니다.

암호가 걸렸거나 손상·분할·중첩된 압축파일은 미리보기가 제한될 수 있습니다. 미리보기를 만들 수 없는 파일은 파일 위치를 열어 직접 확인할 수 있습니다. 미리보기는 원본을 수정하지 않습니다. **이름 변경·삭제를 직접 실행하면 원본 압축파일의 이름이 바뀌거나 휴지통으로 이동합니다.** 즐겨찾기는 파일 경로 기준으로 저장하며 앱 안에서 이름을 변경하면 새 경로를 반영합니다.

## 문제를 발견했나요?

[Issues](https://github.com/sin871220/File-Tripitaka/issues)에 **운영체제 버전, Mac 칩 종류 또는 Windows CPU, 파일 형식, 문제가 생긴 순서**를 적어 주세요. 화면을 첨부한다면 개인 이미지와 민감한 경로는 가려 주세요.

<summary><strong>설정·캐시·로그 위치와 미리보기 제한</strong></summary>

| 운영체제 | 저장 위치 |
|---|---|
| Windows | `%LOCALAPPDATA%\ArchiveShelf` |
| macOS | `~/Library/Application Support/File Tripitaka` |

`settings.json`에는 설정과 즐겨찾기, `cache/`에는 썸네일이 저장됩니다. **영역 편집 내용은 `thumbnail_edits.json`**에 따로 저장합니다. 다른 컴퓨터로 편집 내용을 옮기려면 앱을 닫고 이 파일을 대상 컴퓨터의 같은 설정 폴더로 복사하세요. 캐시만 옮겨서는 영역 편집 내용이 유지되지 않습니다. 오류를 살펴볼 때는 `error.log`와 `crash.log`를 확인하세요. 로그를 공개하기 전에는 개인 경로와 민감한 내용이 들어 있는지 확인해 주세요.

Mac에서 이전 소스 실행으로 만든 `~/.local/share/ArchiveShelf/settings.json`이 있으면 새 저장 위치로 한 번 가져옵니다. Windows의 기존 설정 위치는 유지합니다. Windows에서 언어를 바꾸면 현재 EXE를 가리키는 기존 바탕화면 바로가기 이름도 변경합니다.

대표 이미지 데이터는 압축 해제 후 64MB까지 처리합니다. 큰 이미지 디코더는 별도 프로세스에서 한 장씩 실행하며 메모리(RSS 512MB)와 시간(45초) 제한을 적용합니다. 미리보기 실패 항목은 설정한 열기 동작 대신 파일 위치를 엽니다. **없음·즐겨찾기 전환**은 예외입니다.

<summary><strong>소스로 실행하거나 직접 빌드하기</strong></summary>

Python 3.12 이상과 Tcl/Tk가 필요합니다.

```sh
python -m pip install -r requirements.txt
python app.py
```

Windows 소스 실행은 **새 버전 ZIP을 새 폴더에 전부 푼 뒤 그 폴더의 `run-windows.bat`**을 실행하세요. 실행 창에 실제 소스 폴더와 버전이 표시됩니다. 공유폴더(UNC 경로)도 지원하며, 실행 준비에 실패하면 다른 버전으로 넘어가지 않고 오류를 표시합니다.

공유폴더를 통해 다른 Windows 컴퓨터로 옮겨 테스트할 때는 `python scripts/package_windows_test.py`로 **Windows-Test.zip 하나**를 만들 수 있습니다. 코드·아이콘·글꼴과 실행 배치가 한 버전 폴더에 들어가며, Git 미추적 신규 모듈도 포함합니다. ZIP 전체를 옮겨 새 폴더에 푼 뒤 그 안의 배치를 실행하세요. 이 테스트 ZIP에는 Python이나 EXE가 포함되지 않습니다.

**배포 ZIP과 소스 테스트 ZIP은 다릅니다.** GitHub Releases의 `Windows-x64`·`macOS-arm64`·`macOS-x86_64` 패키지는 Python을 포함합니다. `python scripts/package_windows_test.py`로 별도로 만드는 `Windows-Test.zip`은 소스 실행용이므로 Windows용 Python 3.12 이상을 따로 설치해야 합니다. 현재 공개 배포 버전은 1.3.0입니다.

- Windows: 소스 실행은 `run-windows.bat`, 배포 빌드는 `build-windows.bat`.
- macOS: `build-macos.sh`. Apple Silicon과 Intel은 해당 CPU용 Python 환경에서 각각 빌드합니다.
- GitHub Actions: 버전 태그를 푸시하면 Windows·Mac의 테스트, 빌드, 패키징 점검을 통과한 파일을 배포합니다. 정식 버전은 일반 Release로, `-beta.`가 붙은 버전은 prerelease로 배포합니다. 수동 실행은 빌드 산출물을 만듭니다.
